- **VICTR**, VICTR: Value-Informed In-Context Learning for Vision-Language-Action Models. [![arXiv](https://img.shields.io/badge/arXiv-2611.08698-b31b1b.svg)](https://arxiv.org/abs/2611.08698) — *Luca Macesanu, Tianluo Zhang, Aditya Patil et al.*

  Recent advances in robot foundation models have highlighted the potential of in-context learning (ICL) for adapting robot behavior from demonstrations without further fine-tuning. Previous work has used retrieval-based post-training to equip pretrained vision-language-action (VLA) models with the capability for ICL by teaching them to condition action predictions on retrieved visually-relevant demonstration chunks. However, the effectiveness of retrieval hinges on selecting context relevant to the current execution stage, which visual similarity alone may not capture. We introduce VICTR, a framework enabling in-context learning in VLAs via progress-informed context retrieval built around an In-Context Value Function Estimator (IC-VFE).
