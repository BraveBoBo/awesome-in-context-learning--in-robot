- **World In-Context Learning for Agentic Robot Manipulation**. [![arXiv](https://img.shields.io/badge/arXiv-2611.12885-b31b1b.svg)](https://arxiv.org/abs/2611.12885) — *Heng Fang, Zehui Guo, Yuehan Zhang et al.*

  Trained action policies write manipulation skill into network weights, tying what is learned to the distribution it is learned from. In-context learning (ICL) avoids this coupling but has not matched trained policies, because a demonstration recorded in another scene carries no feedback from the world the robot currently faces. We observe that what an agent learns in context is semantic, recording task steps and object roles rather than visual appearance, so experience gathered in one world transfers to another. Based on this insight, we propose World In-Context Learning (WICL), a paradigm in which a frozen model starts from a demonstration, rehearses the task in a world such as a simulator, and writes the feedback into its context rather than its weights.
